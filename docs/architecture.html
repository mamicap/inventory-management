Factory Inventory Management System

Architecture overview of a full-stack demo application: a Vue 3 single-page app, a FastAPI service, and in-memory mock data loaded from JSON files. There is no database.

Data flow

How a filter change on the Dashboard becomes updated numbers on screen.

  1. User changes a filterFilterBar updates the shared refs in useFilters: period, location, category, status.
  2. View reactsA watch in the view calls getCurrentFilters(), which maps names to API params (location to warehouse, period to month).
  3. API client builds the requestapi.js drops any filter set to 'all' and issues parallel GETs.
  4. FastAPI filters in memoryThe route applies apply_filters and filter_by_month to the module-level lists.
  5. Response is validated and returnedPydantic checks the shape; JSON goes back to the browser.
  6. View recomputesRaw data lands in refs; derived figures and SVG charts come from computed properties.

month accepts a month such as 2025-01 or a quarter key from QUARTER_MAP (Q1-2025 to Q4-2025). Inventory has no date field, so it ignores month.

Observations from the code

Things worth knowing before extending the system.

  • Backlog view is not routed. views/Backlog.vue exists, but main.js registers no /backlog route and the nav has no link. Backlog data surfaces through the Dashboard instead.
  • Purchase orders are read-only. A CreatePurchaseOrderRequest model exists in main.py, but no POST endpoint uses it, and purchase_orders.json is empty.
  • Restocking orders are the only write path. POST /api/restocking-orders appends to an in-memory list, so submitted orders disappear when the backend restarts. Lead times are mock values per category in LEAD_TIME_DAYS.
  • Dashboard summary ignores filters for backlog. total_backlog_items counts all backlog items regardless of the active filters.
  • Quarter logic is duplicated. /api/reports/quarterly re-implements the quarter mapping instead of reusing QUARTER_MAP.
  • Hardcoded API URL. api.js targets http://localhost:8001/api, so deploying elsewhere needs a config change.
  • Demo-only security posture. No authentication, CORS open to all origins, and the signed-in user in useAuth.js is static mock data.
